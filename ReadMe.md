## ✨ 功能亮点

- **BLE 心率实时监测**：自动扫描附近支持标准心率服务（Heart Rate Service）的蓝牙设备，实时显示心率值。
- **悬浮心率窗口**：半透明可拖动悬浮窗，始终显示当前心率；支持**固定（鼠标穿透）与置顶**。
- **历史心率曲线**：独立深色窗口，粉色平滑曲线展示历史心率；显示最高/最低值。
- **蓝牙断线自动重连**：意外断开后每 5 秒自动尝试重连。
- **配置文件持久化**：设置保存在 `%APPDATA%\Heart\config.ini`，记录心率窗口位置等。

## 使用指南
启动后自动开始扫描蓝牙设备，扫描结果会显示在列表中（已过滤无名或无效设备）。
选择目标设备，点击 “连接设备”。
悬浮窗将显示实时心率；右键悬浮窗可固定/取消固定。
勾选主界面的 “置顶并固定” 复选框，可使窗口同时置顶、固定且鼠标穿透。
点击 “💗 心率曲线” 可查看历史曲线图。
关闭主窗口时，程序最小化至系统托盘，右击托盘图标可完全退出。

## ⚙️ 配置说明
配置文件自动创建于 %APPDATA%\Heart\config.ini，内容示例：

>ini
[HeartRateWindow]
x = 100
y = 200
保存心率悬浮窗位置，下次启动自动恢复。

### ❓ 常见问题
- Q：扫描不到任何设备？

确保电脑蓝牙已开启，且设备支持 Bluetooth Low Energy (BLE) 及心率服务。

如果仍然无法扫描，请尝试以管理员身份运行程序，或检查 Windows 蓝牙设置。

- Q：心率显示为 “ERR” 怎么办？

部分设备可能发送非标准数据包，软件会自动尝试解析，错误时显示 “ERR” 但不影响连接。

重新连接或更换设备通常可解决。

- Q：固定后无法取消固定？

取消主界面“置顶并固定”复选框，或右键悬浮窗选择“取消固定”。

- Q：开机自启失效？

请检查 %APPDATA%\Microsoft\Windows\Start Menu\Programs\Startup 中是否存在 HeartRateMonitor.lnk，如被安全软件阻止，请手动添加或关闭防护。
